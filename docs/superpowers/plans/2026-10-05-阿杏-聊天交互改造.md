# 阿杏聊天交互改造 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把阿杏前端的「聊天」修成正常对话——自己的话立即上屏、AI 回复流式 Markdown 渲染、卡片带头像、「你可以这样问」沉底并真实发送、右上角小字门店/拨打、上传改底部浮窗。

**Architecture:** 抽出 shell 级「常驻聊天中枢」`chat-core.js`（持有时间线、发送/停止/历史，不随 view 卸载）；把 `ynet-render-markdown` 的 H5 核心 vendor 进 `src/axing/js/vendor/markdown/` 并用 `markdown.js` 包出流式渲染 API；Composer / 建议 chip / 语音统一走 `chat-core.turn()`；上传从全屏 `#view-upload` 改为 0.15s 底部浮窗。后端 Agents SDK（`chat-guide-agent.js`）与 SSE `/api/chat/guide/stream` 不动。

**Tech Stack:** 原生 ES module + 现有 Express 后端；`@openai/agents@0.17.0`（已就位，不碰）；Playwright（自带端口实例）。

**Spec:** `docs/阿杏交互规范.md`（v1.1）；需求证据：`docs/需求记录-阿杏交互规范.md`（P1–P9）。

// markdown.js — 包 vendor/markdown 的流式渲染 façade（契约见 Task 1 Interfaces）
import { MarkdownStreamEngine, MarkdownRenderView } from './vendor/markdown/index.js';

export function createMdRenderer(container) {
  const engine = new MarkdownStreamEngine();
  const view = new MarkdownRenderView(container);
  const flush = () => view.renderJson(engine.snapshot());
  return {
    append(chunk) { engine.append(String(chunk || '')); flush(); },
    setFull(md) { engine.reset(); engine.append(String(md || '')); flush(); },
    clear() { engine.reset(); container.replaceChildren(); },
  };
}
```

// 消费 SSE /api/chat/guide/stream；每个 handlers.* 可选
chatGuideStream({ message, history = [] } = {}, h = {}) {
  return (async () => {
    const res = await fetch('/api/chat/guide/stream', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ message, history }),
      signal: h.signal,
    });
    if (!res.ok || !res.body) throw new ApiError('阿杏没接上线，再试一次', res.status);
    const reader = res.body.getReader();
    const dec = new TextDecoder();
    let buf = '';
    for (;;) {
      const { value, done } = await reader.read();
      if (done) break;
      buf += dec.decode(value, { stream: true });
      let i;
      while ((i = buf.indexOf('\n\n')) >= 0) {
        const raw = buf.slice(0, i).trim(); buf = buf.slice(i + 2);
        const line = raw.startsWith('data:') ? raw.slice(5).trim() : raw;
        if (!line) continue;
        let ev; try { ev = JSON.parse(line); } catch { continue; }
        const fn = { status: h.onStatus, thinking: h.onThinking, tool: h.onTool, delta: h.onDelta, done: h.onDone, error: h.onError }[ev.type];
        if (fn) fn(ev);
      }
    }
  })();
},
```

**Files:**

**Interfaces:**
- Consumes: `createMdRenderer`（Task 1）；`api.chatGuideStream`（Task 2）；`ctx.{ui,on,emit,toast,humanError,state}`。
- Produces: `initChatCore(ctx) -> { mount(container): void; turn(text: string): Promise<void>; stop(): void; isBusy(): boolean; render(): void; destroy(): void }`
  - `turn(text)`：立即 echo 用户右气泡（带时间戳）→ 「正在想」占位 → 流式建一条阿杏左气泡，delta 走 `createMdRenderer.append` → `done` 后 `setFull` 标准化 → 失败补兜底话术（时间线不留空洞）。随身携带最近 6 轮上下文。
